# LedgerLens 核心需求

目标：将定期导出的消费账单集中处理，优先保证记账精准，同时减少手动操作。

- 处理日常支出、收入及账户转账；当前原型的数据来源是微信与支付宝。
- 当前选择 ezBookkeeping 作为记账主界面；仅电脑端使用，双击入口按需启动，不常驻后台。
- 同一交易的重复来源只计一次；重复或重叠导入不新增重复交易。
- 自有账户转移不计收入和支出；他人转账按实际用途判断。
- 全额、部分及分笔退款关联原消费，避免误计收入或重复抵扣。
- 所有金额严格小于 1 元的流水（含收入、支出、退款和转账）屏蔽，不参与审核和统计；原始记录保留，恰好 1 元保留。
- 不确定的分类和关联交给人工，确认前不强行合并、删除或宣称最终统计准确。
- 疑点确认前不写入正式账本；界面提示待审核数量及统计不完整。审核交互从简，支持确认、修改、暂缓和保存进度。
- 可以配置云端 AI API，但必须明确发送哪些数据，AI 不能替代人工确认。

这是需求，不是已完成能力的声明。当前实现边界见 README；银行卡与支付平台的跨源去重需要银行数据才能验证。
